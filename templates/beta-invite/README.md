# You're in

An invite code on a ticket with a real expiry. Exclusive because it is.

<img src="preview.webp" width="420" alt="You're in preview">

- **Its job:** Activate waitlisted people when they're let in.
- **Send it:** When a batch of the waitlist is invited.
- **Why it works:** Real exclusivity (a code, an expiry) creates urgency without tricks.
- **Measure:** Code redemption within 7 days
- **Keep:** the code; the expiry
- **Avoid:** fake scarcity
