# Better with two

Shows sharing with their own work's name, and a pre-filled invite.

<img src="preview.webp" width="420" alt="Better with two preview">

- **Its job:** Get the first teammate invited.
- **Send it:** After the first project is created, if they work alone.
- **Why it works:** Uses their own project's name (ownership) and makes the invite one click.
- **Measure:** Invites sent within 7 days
- **Keep:** their project name
- **Avoid:** seat-pricing talk

**Subject lines to test**

- Who else should see {{project_name}}?
- {{project_name}} is better with two
- Invite one person to {{project_name}}

Slots: `preheader`, `user_initials`, `project_name`, `summary`, `cta_label`, `cta_url`
