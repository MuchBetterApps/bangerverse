# Why did you leave?

Five one-click reasons; each can branch the journey to a matching reply.

<img src="preview.webp" width="420" alt="Why did you leave? preview">

- **Its job:** Learn why people cancel, and save the savable.
- **Send it:** Right after cancellation.
- **Why it works:** One-click reasons get answered; each link can trigger a tailored follow-up (a discount for price, a roadmap note for features).
- **Measure:** Response rate; saves from 'too expensive' and 'missing feature'
- **Keep:** one-click reasons; no guilt
- **Avoid:** a win-back offer before they answer

**Subject lines to test**

- Before you go: one click?
- Why did you cancel?
- Help us get better (one tap)
