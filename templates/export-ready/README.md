# Export ready

A file card with size and expiry, and one download button.

<img src="preview.webp" width="420" alt="Export ready preview">

- **Its job:** Deliver the file.
- **Send it:** When an async export or report finishes.
- **Why it works:** The file card answers 'is this the right file?' before they click.
- **Measure:** Downloads
- **Keep:** file details; expiry
- **Avoid:** upsells

**Subject lines to test**

- Your export is ready
- {{file_name}} is ready to download
- Done: your export

Slots: `preheader`, `headline`, `file_type`, `file_name`, `file_meta`, `cta_label`, `cta_url`, `expires_in`
