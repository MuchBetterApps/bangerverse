# You were mentioned

The quoted comment with who wrote it, so people can answer without opening the app.

<img src="preview.webp" width="420" alt="You were mentioned preview">

- **Its job:** Get a fast response to a teammate.
- **Send it:** When someone is @mentioned (batched if several within minutes).
- **Why it works:** Quoting the actual comment gives enough context to reply straight from the inbox.
- **Measure:** Time to response
- **Keep:** the quote; the author
- **Avoid:** multiple threads in one email

**Subject lines to test**

- {{author_name}} mentioned you in {{thread_name}}
- {{author_name}}: “Can you check the numbers…”
- New mention in {{thread_name}}

Slots: `preheader`, `author_name`, `thread_name`, `author_initials`, `posted_at`, `comment`, `cta_label`, `cta_url`
