# Password reset

Reset instructions with a clear expiry and a calm note for people who didn't ask.

<img src="preview.webp" width="420" alt="Password reset preview">

- **Its job:** Get the person back into their account.
- **Send it:** When a reset is requested.
- **Why it works:** Names the account and the expiry; reassures that nothing changes if they ignore it.
- **Measure:** Reset completion
- **Keep:** the account email; expiry; ignore-if-not-you note
- **Avoid:** anything promotional

**Subject lines to test**

- Reset your {{company_name}} password
- Your password reset link
- Get back into {{company_name}}

Slots: `preheader`, `headline`, `cta_label`, `cta_url`, `expires_in`
